# الرؤية الاستراتيجية 2030 — بلدية طرابلس المركز

صفحة ثابتة لاستضافة وتحميل وثيقة **الرؤية الاستراتيجية 2030** الصادرة عن بلدية طرابلس المركز. تتضمن الصفحة رمز QR محلي التوليد يفتح صفحة تنزيل ثابتة.

## الروابط

- صفحة الموقع: `https://mustafaaldernawi.github.io/vision-2030-qr/`
- صفحة التنزيل: `https://mustafaaldernawi.github.io/vision-2030-qr/download.html`
- ملف PDF: `https://mustafaaldernawi.github.io/vision-2030-qr/documents/vision-2030.pdf`

## تحديث الوثيقة

استبدل الملف فقط في `documents/vision-2030.pdf` مع الحفاظ على الاسم والمسار، ثم ادفع التغيير إلى فرع `main`. يبقى رابط صفحة التنزيل ورمز QR صالحين لأنهما يشيران إلى `download.html` الثابتة، لا إلى نسخة محددة من الملف.

## النشر

ينشر GitHub Actions الموقع عند كل دفع إلى `main` عبر GitHub Pages. لا توجد تبعيات تشغيلية أو خدمات خارجية: مكتبة QR موجودة محلياً في `assets/js/qrcode.min.js`، والملف الأصلي موجود داخل الموقع.
